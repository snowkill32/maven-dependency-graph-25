# Зависимости Maven: учебная реализация с начала

Практическая работа №2, вариант 25.

Эта ветка содержит повторную учебную реализацию по небольшим шагам.
Готовая версия этапов 1 и 2 сохранена в ветке `main` того же репозитория.

Добавлены четыре параметра командной строки и вывод конфигурации
первого этапа. Проверку формата значений добавим следующим шагом.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки и сборка не нужны.
Из корня проекта:

```shell
python -m src --package junit:junit:4.13.2 --repository https://repo1.maven.org/maven2/
python -m src --help
```

В Windows также можно использовать:

```powershell
.\run.bat --package junit:junit:4.13.2 --repository https://repo1.maven.org/maven2/
.\run.bat --help
```

Успешный запуск печатает:

```text
package=junit:junit:4.13.2
repository=https://repo1.maven.org/maven2/
test_mode=false
ascii_tree=false
```

## Параметры

| Опция | Назначение | По умолчанию |
| --- | --- | --- |
| `--package` | Координаты Maven или имя тестового пакета | Обязательна |
| `--repository` | URL репозитория или путь к тестовому файлу | Обязательна |
| `--test-mode` | Работа с локальным тестовым репозиторием | `false` |
| `--ascii-tree` | Настройка ASCII-дерева, которое появится на этапе 5 | `false` |

Флаги включаются присутствием: `--test-mode`, без `=true`.
Справка и обычный запуск возвращают код `0`. При отсутствии обязательных
опций или неизвестном аргументе `argparse` выводит ошибку в stderr и код `2`.

На первом этапе зависимости не загружаются, выводится только конфигурация.

## Файлы и функции

- `src/__main__.py` запускает приложение через `python -m src`.
- `src/cli.py`: `build_parser()` описывает опции, `parse_config(argv)`
  получает значения, `format_config(config)` формирует вывод.
- `main(argv)` запускает чтение и вывод; при `argv=None` читаются
  аргументы текущего процесса.
- `src/config.py`: неизменяемый `Config` хранит четыре настройки.
- `run.bat` запускает программу из каталога проекта и сохраняет код выхода.
- `tests/` зарезервирован для тестов следующих шагов; сейчас тестов нет.

Текущий шаг проверяется обычным запуском, включением двух флагов,
просмотром справки и запуском без обязательных опций.
