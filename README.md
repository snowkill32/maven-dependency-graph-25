# Зависимости Maven: учебная реализация с начала

Практическая работа №2, вариант 25.

Эта ветка содержит повторную учебную реализацию по небольшим шагам.
Готовая версия этапов 1 и 2 сохранена в ветке `main` того же репозитория.

Сейчас сделан только минимальный запуск CLI. Приложение показывает
сообщение о запуске и поддерживает `--help`. Параметры пакета и репозитория
будут добавлены следующим шагом первого этапа.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки и сборка не нужны.
Из корня проекта:

```shell
python -m src
python -m src --help
```

В Windows также можно использовать:

```powershell
.\run.bat
.\run.bat --help
```

Успешный запуск печатает:

```text
Приложение анализа зависимостей Maven запущено.
```

Справка и обычный запуск возвращают код `0`.
Неизвестные аргументы обрабатывает `argparse`: сообщение в stderr и код `2`.

## Файлы и функции

- `src/__main__.py` запускает приложение через `python -m src`.
- `src/cli.py`: функция `main()` создает парсер, читает аргументы,
  печатает сообщение и возвращает код успеха.
- `run.bat` запускает программу из каталога проекта и сохраняет код выхода.
- `tests/` зарезервирован для тестов следующих шагов; сейчас тестов нет.

Текущий шаг проверяется запуском трех команд: без аргументов,
с `--help` и с неизвестным аргументом `--unknown`.
