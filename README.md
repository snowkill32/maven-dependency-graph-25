# Граф зависимостей Maven - вариант 25

Практическая работа №2. Этап 1: минимальный CLI-прототип
с конфигурацией. Python 3.10+, только стандартная библиотека.

Программа принимает опции командной строки, проверяет их и выводит
четыре настройки в формате `ключ=значение`.

```shell
python -m src --package org.example:demo:1.0 --repository https://repo.maven.apache.org/maven2/
```

Справка: `python -m src --help`. В Windows можно использовать
`run.bat`, в Linux/macOS - `sh run.sh` с теми же аргументами.

На этом этапе загрузка зависимостей и построение графа еще не реализованы.
